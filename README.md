# Питание на месяц для двоих

Интерактивный план питания и еженедельных закупок для двух человек в Санкт-Петербурге.

**Актуальный сайт:** [pitanie-na-mesyac-dlya-dvoih-spb.santinoporchi.chatgpt.site](https://pitanie-na-mesyac-dlya-dvoih-spb.santinoporchi.chatgpt.site/)

## Что внутри

- подтверждённые расходы первой недели и прогноз месяца;
- домашние остатки, которые вычтены из будущих закупок;
- меню и точные списки покупок на недели 2–4;
- 33 подробных рецепта с количествами, временем и температурой;
- ротация гречки, булгура, кускуса, пасты и риса;
- ужины-салаты с креветками и кальмаром;
- адаптивный интерфейс для телефона и компьютера.

На неделях 3 и 4 рис используется не чаще одного раза. Перловка в меню не входит.

## Локальный запуск

Требуется Node.js `22.13.0` или новее.

```bash
npm install
npm run dev
```

Production-сборка и тесты:

```bash
npm run build
node --test tests/rendered-html.test.mjs
```

## Структура

- `app/page.tsx` — меню, остатки, закупки и бюджет;
- `app/recipe-details.ts` — подробные рецепты;
- `app/globals.css` — оформление и адаптивность;
- `tests/` — проверки содержимого и ограничений меню;
- `index.html` — совместимый вход для GitHub Pages с переходом на актуальный опубликованный сайт.

GitHub Pages остаётся рабочей точкой входа, а production-версия развёртывается через Sites.
