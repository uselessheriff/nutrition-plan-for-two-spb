# Питание на месяц для двоих

Интерактивный план сбалансированного питания и еженедельных закупок для двоих в Санкт-Петербурге.

Сайт опубликован через GitHub Pages. Откройте `index.html` локально или используйте ссылку GitHub Pages из раздела **About** репозитория.

## Что внутри

- три уровня бюджета: 20 000, 25 000 и 30 000 ₽;
- меню и закупки на четыре недели;
- адаптивная версия для телефона, планшета и компьютера;
- работает без внешних библиотек и сборки.
