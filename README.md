# Питание на месяц для двоих

Интерактивный план питания и еженедельных закупок для двух человек в Санкт-Петербурге.

**Автономная версия на GitHub Pages:** [uselessheriff.github.io/nutrition-plan-for-two-spb](https://uselessheriff.github.io/nutrition-plan-for-two-spb/)

## Что внутри

- подтверждённые расходы четырёх недель, включая уже оплаченную корзину недели 4;
- живая российская дата по часовому поясу `Europe/Moscow`: серверное время сверяется онлайн, а календарная неделя меняется автоматически;
- анализ цен, экономической полезности, стабильности цен и риска списаний;
- числовая память цен: новая покупка сравнивается с предыдущей в ₽/кг, ₽/л или ₽/шт., а аналоги явно отделены от того же товара;
- домашние остатки и уже купленные партии, которые не считаются повторно;
- журнал решений по закупке: купить, уже куплено, убрано из-за остатка, нет цены или нет подтверждения покупки;
- архив рецептов недель 1–3 с отдельным аудитом того, что точно готовили, не ели, только планировали пропустить или пока не подтвердили;
- сохранённые строки прежнего меню недели 3: отменённые блюда не исчезают из истории;
- база рецептов, где результат блюда («готовили», «не ели», «в плане») отделён от оценки вкуса («любимое», «понравилось», «исключено»);
- расчётный модуль следующего месяца: потребность рецептов минус пригодный остаток минус уже купленное, с округлением до фасовки;
- протокол месячного разбора: что купили, что приготовили, что отменили, сколько порций вышло и почему возникло списание;
- 40 подробных рецептов с количествами, временем и температурой;
- ротация гречки, булгура, кускуса, пасты и риса;
- разные выходные завтраки: пшённая каша, сырники, омлет и каша «Дружба»;
- ужины-салаты с кальмаром и креветками;
- шесть коротких адаптивных вкладок вместо одной длинной страницы; верхняя навигация прокручивается на телефоне.

На неделе 4 рис используется как гарнир один раз; каша «Дружба» — отдельный завтрак. Белая рыба, белокочанная капуста и перловка исключены из будущего меню; стручковая фасоль допустима только внутри овощной смеси. Для следующего планового цикла зафиксированы периодические выходные обеды-выпечка и картофельное пюре как иногда используемый гарнир. Каноническая опубликованная версия всегда доступна на GitHub Pages по ссылке выше.

## Локальный запуск

Требуется Node.js `22.13.0` или новее.

```bash
npm install
npm run dev
```

Production-сборка и тесты:

```bash
npm run build
npm test
```

Статическая сборка для GitHub Pages:

```bash
npm run test:github-pages
```

## Структура

- `app/page.tsx` — интерфейс меню, анализа, закупок и бюджета;
- `app/plan-data.ts` — меню, остатки, чеки, закупки и рейтинг продуктов;
- `app/meal-history.ts` — доказательная история блюд недель 1–3 без вывода «готовили» по одному лишь меню или чеку;
- `app/plan-calendar.ts` — московская дата, календарные диапазоны недель 1–4 и онлайн-сверка времени;
- `app/recipe-details.ts` и `app/recipe-details-revised.ts` — подробные рецепты;
- `app/shopping-planner.ts` — нормализованный расчёт потребности, остатков, уже купленного и фасовок;
- `app/globals.css` — оформление и адаптивность;
- `tests/` — проверки содержимого и ограничений меню;
- `github-pages-main.tsx` — клиентская точка входа автономной версии;
- `vite.github-pages.config.ts` — статическая сборка в каталог `docs/`;
- `index.html` — HTML-вход автономной версии GitHub Pages.

GitHub Pages публикуется из `docs/` и не зависит от домена Sites.
